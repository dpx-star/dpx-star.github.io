INSTALLATION

Getting started with DPX

1

Download DPX

Download the latest DPX Windows installer and complete the installation.

Download DPX-Setup.exe
2

Install Java

DPX currently runs on Java. Install Java 21 for the current DPX release.

Make sure Java is installed before running DPX.

3

Refresh your PowerShell PATH

After installing DPX, open PowerShell and run: 

$env:Path = [Environment]::GetEnvironmentVariable("Path", "Machine") + ";" + [Environment]::GetEnvironmentVariable("Path", "User")

This refreshes the current PowerShell session so it can find the newly installed dpx command.

4

Test DPX

Run: 

dpx version

You should see the installed DPX version.

5

Install packages

Search the repository and install packages directly from the command line: 

dpx search minecraft
dpx info minecraft-bot
dpx install minecraft-bot

Command-line installation is the main way to use DPX.

!
IMPORTANT

Java is currently required

DPX 0.1.1 currently requires Java to run. Java 21 is recommended for the current release. A future DPX release may bundle a Java runtime so users do not have to install Java separately.
