Installation

1

Install DPX

Download and run the DPX installer.

2

Install Java 21

DPX currently requires Java. Install Java 21 ↗

3

Refresh PowerShell

Run this command after installing DPX so your current PowerShell session can see the DPX command.

$env:Path = [Environment]::GetEnvironmentVariable("Path", "Machine") + ";" + [Environment]::GetEnvironmentVariable("Path", "User")
4

Test DPX

Check that DPX is installed correctly.

dpx version
5

Install packages

DPX's main purpose is installing packages from the public repository.

dpx install example
Java requirement: Java 21 is recommended for the current DPX release. A future version of DPX may bundle its own Java runtime.
